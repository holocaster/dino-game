## Evidência literal

> Unity's Web platform supports the following mobile browsers:

> iOS Safari 15 and newer

> Chrome 58 and newer

## O que sustenta

Unity 6.6 lista Safari iOS 15+ e Chrome Android 58+ na matriz web móvel. Desktop exige WebGL2, HTML5, browser 64-bit e WebAssembly. É incorreto rejeitar essa versão com a frase antiga de que Unity Web não suporta navegadores móveis. O próprio manual recomenda navegadores atuais e ressalva problemas em versões antigas.
