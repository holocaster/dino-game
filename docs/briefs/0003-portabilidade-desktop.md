# 0003 — Portabilidade para desktop

Status: feature futura, registrada em 2026-11-17; sem implementação ou versão prevista.

## Objetivo

Disponibilizar o jogo como executável nativo para Windows, Linux e macOS, mantendo a versão web e compartilhando o mesmo projeto Godot.

## Escopo previsto

- Reutilizar corrida, regras, modelos e animações existentes.
- Levar menus, seleção de dinos/pistas/modos, interface da corrida, áudio, álbum e salvamento de preferências para o Godot, removendo a dependência da página web para jogar no desktop.
- Preservar os modos Rival, Sozinho e Dupla, incluindo pausa, reinício e retorno ao menu.
- Configurar os templates e presets de exportação para cada sistema.
- Definir assinatura e notarização para distribuição no macOS.

## Validação futura

Conferir a experiência completa e a persistência local em cada sistema, além de verificar que a versão web continua funcionando. A migração de adesivos e preferências já salvos no navegador será uma decisão do planejamento.
